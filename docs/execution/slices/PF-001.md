## Acceptance criteria

1. The working installation and Next cannot collide under default launch/dev
   configuration.
2. Stable upstream cannot be pushed from the Next checkout.
3. Master plan, requirements, boundaries, current state, pickup, routing, and
   next slice form one consistent authority chain.
4. Historical implementation plans are visibly historical/provisional.
5. CI and launcher/static validation pass.
