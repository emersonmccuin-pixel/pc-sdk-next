# BC-001: Evidence-backed baseline characterization

Status: ready for user review; no worktree provisioned.

## Objective

Map the actual PC-SDK Next implementation to its component boundaries and
accepted requirements before choosing the first behavioral migration.

## Scope

Read-only evidence gathering across runtime/session persistence, conversation
ordering and replay, orchestration/agent communication, contracts/worktrees,
permissions/environment handling, recovery, and browser behavior. In parallel,
begin the AInativePM discovery lanes only after its repository is confirmed in
scope.

No application behavior, schema, event contract, or integration changes.

## Parallel agent plan

1. Runtime/session/capability and provider-leak audit
2. Conversation/chat/send-queue/replay and UI-state audit
3. Agent/contracts/worktree/security/recovery audit
4. Root synthesis, dependency graph, and contradiction resolution

AInativePM domain/UI/MCP investigation may run as a separate read-only slice if
the evidence volume would pollute this one.

## Deliverables

- As-built component/data ownership map with file and table references
- Requirement implementation/status corrections
- Characterization-test gaps and proposed guard tests
- Dependency-ordered migration slices for N2–N5
- Risks requiring user decisions

## Gate

The user reviews the evidence and approves the first behavior-changing slice.
