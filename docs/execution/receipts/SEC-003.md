## Delivered invariant

Every current production provider runtime, app-owned Git command, setup/
readiness/verification/cleanup shell, and fixed Windows tree-kill helper starts
from one provider-neutral positive inherited-environment allowlist. The list
contains only explicit OS execution, home/config, temporary, locale, and
terminal names. Unknown names do not cross merely because nobody anticipated
that they might contain a secret.

Windows keys are matched case-insensitively and emitted canonically. Multiple
spellings of one allowed name are ambiguous and all are omitted; non-ASCII
case-fold lookalikes are rejected before matching. POSIX keys must match exact
uppercase names. Undefined, NUL-bearing, and exported-shell-function values
are omitted, and caller-owned inputs are not mutated.

Consequently `PC_AINATIVE_PM_TOKEN`, `PC_DATA_DIR`, OpenAI/Anthropic/API auth,
ambient runtime homes, `GIT_DIR`/`GIT_WORK_TREE`/`GIT_COMMON_DIR`,
`NODE_OPTIONS`, `BASH_ENV`, dynamic-loader controls, package auth, and arbitrary
canaries are unavailable to those children. The obsolete narrow Git-only
helper is deleted so direct Git and shell/runtime children cannot drift.

Profile and verification commands share one executor, so setup, readiness,
cleanup, verification, and all grandchildren inherit the same reduced map.
The executor pins `/bin/sh` on POSIX or a real absolute `cmd.exe` derived from
consistent allowlisted SystemRoot/Windir evidence on Windows, overwrites child
`COMSPEC`, and returns typed exit 127 when that evidence is unavailable.
Ambient parent `ComSpec` cannot select an executable.

Claude account env adds exactly the PC-SDK-selected `CLAUDE_CONFIG_DIR` after
allowlisting. `ClaudeRuntimeSession` sanitizes on construction and again at the
final query options seam. A missing, relative, padded, inherited, lowercase-
lookalike, or otherwise malformed home fails closed rather than resuming or
minting under a default account. Raw API credentials cannot shadow the
subscription login or trigger an API-billing fallback.

MCP stdio retains its intentionally separate boundary: the pinned MCP SDK's
small default environment plus explicit stored per-consumer `config.env`.
Tests prove ambient canaries are absent while explicit attachment values remain
present. The only broad production environment copy is the trusted same-engine
restart, which must retain PC-SDK configuration; source guards classify it
exactly. Launcher/browser environment separation remains N7.
