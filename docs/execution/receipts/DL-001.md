## Delivered invariant

Every fresh repository builder and continuation now owns immutable, explicit
preparation and readiness evidence before provider runtime mint or send.
Configured commands record a nonempty `executed` receipt. An empty configured
phase records `not-required/no-commands-configured`; a continuation records
`not-required/existing-worktree-preparation` bound to its exact parent before
re-running readiness or recording its readiness no-op.

Domain, DTO, persistence, and dispatch guards all validate exact
outcome-specific shapes. Executed evidence is positive only when every command
exits zero without timing out. Preparation authority is contextual: fresh runs
cannot claim inherited work, and continuations cannot claim fresh preparation
or a different parent. Readiness cannot be persisted before positive
preparation. Receipts are first-write CAS values restricted to the
queued/preparing pre-runtime state.

The runtime door revalidates exact Git identity/path/base evidence plus both
positive phase receipts. The same guard fences paused-run revival. Missing,
negative, malformed, stale, phase-mismatched, or context-mismatched evidence
fails closed and preserves the worktree. Cancellation is rechecked after
asynchronous repository-lease admission and before each later profile command;
a cancelled phase publishes no late receipt and never mints a runtime.

Migration `0016` promotes only exact command-bearing legacy receipts. Empty,
malformed, discriminator-forged, runtime-incompatible, or context-incompatible
values become unavailable. Its SQL checks match runtime command trimming and
ULID rules, including SQLite three-valued-null cases. Historical agent-run
outbox frames carrying the old nested shape are invalidated while unrelated
resource replay remains. New canonical receipts are preserved deterministically.

The browser distinguishes executed evidence, explicit positive no-ops, and
unavailable applicable evidence. Non-repository runs and detached reviewers
retain null semantics; no builder receipt is misrepresented as authority for a
different detached checkout.
